# Ivan Shevchuk — public freelance portfolio

Live: https://ivanshevchuk0.github.io/

Static HTML/CSS/JS, published by GitHub Pages from main at repository root. No build or paid dependency required. This dedicated deployment repository contains only the audited portfolio, local font licenses and sanitized reporting example.

Run locally:

    python3 -m http.server 8874 --bind 127.0.0.1

Edit index.html/styles.css/app.js and commit to main. GitHub Pages publishes the new commit. Root-relative links assume this user-site domain.

The examples/reporting source uses fictional records. No client records, sales history, credentials, identity documents or team-owned Sealdesk source are included. Sealdesk is linked to its existing public repository and credited as team work. The website concept is not commissioned work.

Contact prepares a mailto draft; nothing is sent by the website. No testimonials, customers, income or production certification are claimed. _headers is retained for portability but GitHub Pages does not apply Cloudflare custom headers.
